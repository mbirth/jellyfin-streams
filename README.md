Stream Collection
=================

KODI supports [.STRM files](https://kodi.wiki/view/Internet_video_and_audio_streams) which only contain the URL
to some online video file and will handle it like any other video file. It will show up in your library as if you
had the movie locally.

Turns out, Jellyfin supports those, too.

So, this is my collection of .STRM files.


> [!IMPORTANT]
> These `.STRM` files merely contain URLs. This repository does not contain any copyright-infringing material. It is just
> a catalog of links. The actual video files these `.STRM` files point to are **not** mine and not hosted by me.
> I have no control over them.

**PULL REQUESTS WELCOME!**


Internet Archive Search
-----------------------

> [!TIP]
> To easily find more movies and shows, search the Internet Archive for e.g.:
>
> ```
> title:("movie or show name goes here") AND mediatype:(movies)
> ```
> 
> Then sort the results by "All-time views".

> [!NOTE]
> Often, the IA's derive process created a separate `.mp4` file, sometimes `.ia.mp4`. In many cases it makes
> sense to use this for streaming instead of the 10 GB 8k-video file as the larger one would never download
> fast enough to watch it while it still downloads.


> [!NOTE]
> Some of these `.STRM` files point to video files inside archives (zip/7z/etc.). The Internet Archive
> doesn't support HTTP Range requests for those files. So, scrubbing/seeking won't work with them. You'll
> have to sit through them from beginning to end. (Unless your client has downloaded ahead.)

> [!IMPORTANT]
> Consider [donating to the Internet Archive](https://archive.org/donate).
